# FrameOSU public videos

This independent public repository is cloned at `packages/frameosu/videos/`.
Read [README.md](README.md) and [CODEMAP.md](CODEMAP.md) before changing assets.
Keep publication-ready media under a language code, then purpose and platform.
Preserve captions and capture provenance with guide videos. Never add private
sources, credentials or unfinished recording logs. Commit locally on main;
publishing requires the user's authorization.
